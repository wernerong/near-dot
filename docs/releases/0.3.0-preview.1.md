# Near Dot 0.3.0-preview.1

Prepared desktop installer preview; not yet published or cleared for public binary distribution.

- Guided first-run setup tests and confirms a private destination, personalizes the companion, reviews update preferences and saves completion. Existing verified installations skip repeat setup; incomplete setup resumes, and settings/images survive upgrades.
- Public builds open the tested destination with one click or shortcut. They omit the private relay scripts, chat controls and helper startup. The owner-approved Mac proof remains an explicit development feature; no credentials or personal art are bundled.
- Running version appears in Settings and the tray/menu bar. All app manifests and lockfiles are checked together before builds; native metadata and artifact filenames carry the candidate version.
- Draft release automation covers Windows x64 plus Apple Silicon and Intel Macs. Mac release checks require Developer ID signing, hardened runtime, notarization/stapling, version and architecture. Windows requires Authenticode. Every updater artifact and paused channel file must verify against the shipped Tauri public key; artifact signatures bind their version.
- Preview/stable channels, automatic checks, manual checking, progress/errors, defer/skip and controlled installation/restart remain. Draft feeds start paused at 0%; publication and activation require final review.

The requested live ChatGPT replies and shared conversation history remain unsupported. This preview does not complete the realtime-chat product goal. Browser URLs must be tested per device; ChatGPT authentication/account access can change.

Validation and remaining device/signing gates are recorded in [acceptance evidence](../ACCEPTANCE.md). No production signing keys, paid accounts, public installers or active update feed were created by this preparation.
