# Near Dot 1.1.0

Click the Windows companion or use its shortcut to open your existing ChatGPT dot in a dedicated Microsoft Edge app window. Near Dot restores the same window while it is open, and automatically reopens your saved address after closing it or restarting Windows.

## Changes

- Use the real ChatGPT interface and its normal account, history and plan. No OpenAI API key, separate AI billing, Codex inference or window relinking is required.
- Keep a separate, owner-only Edge profile on this device. Sign in normally once using **Settings → Chat connection → Dedicated ChatGPT window → Test link**, and confirm that the address opens your existing dot. ChatGPT may ask you to sign in again when its session expires.
- Preserve the saved destination, verification, setup, artwork and controls across upgrades. Existing Windows settings without a saved chat mode select the dedicated window. The earlier private relay remains available as an advanced mode.
- Recover safely from a closed window, restarted browser, stale window handle or changed destination. Bound slow Windows process discovery and report retry errors without exposing private launch arguments.
- Retain the browser launcher on Mac; this release does not add the Windows app-window route to Mac.

Near Dot does not read ChatGPT pages, messages, cookies or tokens. ChatGPT owns the conversation shown in its window; there is no second copied transcript. The companion does not mirror ChatGPT-origin reply bubbles, global dot activity or unread counts. A successful OS window launch does not establish that a particular address reaches the correct dot.

## Updates and validation

All application and installer version stamps are 1.1.0. The protected release workflow requires exact-source Windows x64, Mac Apple Silicon and Mac Intel CI, mandatory updater signatures, checksums and provenance. It tests tampered/truncated package rejection, a real Tauri upgrade from the prior 1.0.3 installer, preservation of synthetic preferences and artwork, verified recovery reinstall and executable removal before publication.

Native window tests use synthetic local Edge content. Actual signed-in ChatGPT continuity, MFA, physical-device focus, display scaling and Windows restart behavior remain untested; see [the device checklist](../CHAT-APP.md#acceptance). Hosted tests do not certify power loss during installation or physical OS security prompts.

The signed Stable and Preview feeds will offer 1.1.0 to all rollout cohorts when activated. Automatic checks run about 30 seconds after launch and every six hours when enabled; **Settings and updates → Check for updates** checks immediately. Installation still requires your approval unless you enabled the one-time next-manual-launch option. Settings and personal artwork stay local.

Windows installers retain the approved distribution model without Authenticode signing. Mac bundles are ad-hoc sealed without Developer ID signing or notarization. Mandatory updater signatures remain enabled. Keep OS protections enabled.
