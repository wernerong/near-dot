# Near Dot 0.1.0 — source preview

Independent local launcher with an original transparent companion, optional private local PNG image, settings, tray access, configurable shortcut, position recovery and opt-in login startup. Includes a signed desktop updater adapter and a protected draft-release workflow.

**Development prerelease: source only. No signed desktop installers or configured automatic update feed are included.** Build locally using README commands. Windows x64 is the first installer target; Mac arm64 has a development build and native test evidence, not certified distribution support. Windows signed upgrades/recovery and clean uninstall remain release blockers.

Exact-dot access was verified for one signed-in Mac/Chrome session, including native Test link and Open my dot. Each user and device must test its own link; no public deep-link contract is assumed. Destination, avatar and credentials are not bundled. The iPhone companion is a documented Open ChatGPT Shortcut recipe, untested on device.

Idle movement is decorative. This release cannot read dot activity or messages, show live snippets, automatically retrieve its image or host a conversation with the existing dot. See `docs/ROADMAP.md` for the official integration evidence and next-phase requirements.
