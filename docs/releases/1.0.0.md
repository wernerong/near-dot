# Near Dot 1.0.0

First desktop installer release, based on the committed 0.3.0-preview.1 launcher.

## Install

- **Windows 10/11 x64:** download `NearDot-1.0.0-windows-x86_64.exe` and run it for your user.
- **Apple Silicon Mac:** download `NearDot-1.0.0-darwin-aarch64.dmg`, drag Near Dot to Applications, then launch it there.
- **Intel Mac:** use `NearDot-1.0.0-darwin-x86_64.dmg` with the same steps.

No Node, Rust, terminal, API key or new Near Dot login is needed. The first-run guide tests your own private ChatGPT destination, offers local image/pet-sheet import and explains update preferences. Settings remain local and survive upgrades. Version 1.0.0 is displayed in Settings and the tray/menu bar.

## Included

A compact draggable companion; always-on-top by default; configurable shortcut; tray/menu controls; size, opacity and animation controls; opt-in login startup; original default art and local owned-image import. One click opens the saved, device-tested dot destination.

Automatic update checks run after startup and every six hours, with manual checking, progress/errors, skip/defer and user-controlled installation. Fresh stable installs select the stable channel. Feed and package signatures, signed version, checksum and platform must verify before installation. Private signing keys and account credentials are never bundled.

## Read before installing

The owner approved the same OS distribution model as AI Usage Widget: **Windows installers are not Authenticode signed; Mac bundles are ad-hoc sealed, not Developer ID signed or notarized.** Windows/macOS can warn or block first launch. Keep all OS security protections enabled. If your policy blocks installation, wait for publisher-signed distribution or consult your administrator. Tauri updater signing is a separate cryptographic control and remains mandatory.

This release is a **launcher**. It does not provide two-way desktop conversation, ChatGPT-origin reply bubbles, live task status, automatic avatar sync or shared ChatGPT history. The private experimental relay and its credentials are excluded. No separate assistant or simulated messages replace your dot.

## Verification and known limits

Release jobs check all three architectures, secret/dependency scans, unit/UI checks and real Tauri package rejection/upgrade from the 0.3.0 installer baseline. Hosted install checks preserve synthetic preferences through upgrade and recovery reinstall, then remove the executable. Checksums, package signatures and GitHub provenance accompany the assets.

Hosted runners do not certify every physical-device scenario. Power loss during installation, physical hotkey/monitor/login behavior, native screen readers and iPhone behavior remain untested. See the repository's acceptance checklist. The optional iPhone companion remains a documented Shortcut; mobile Safari is not a dot fallback.
