# Near Dot 1.2.0

Open the dedicated ChatGPT window in the default Chrome or Edge browser, and receive optional notifications beside the pet while keeping the actual conversation in ChatGPT.

## Changes

- Respect Windows' default HTTPS browser. Chrome and Edge use fixed installation paths and their own persistent private profiles and window caches. An unsupported default browser produces an actionable error rather than silently opening Edge.
- Preserve the existing Edge profile, saved dot address, settings and artwork. Switching to Chrome needs one normal sign-in in its separate profile; subsequent launches reuse it without window selection or relinking.
- Add **Incoming reply notifications beside the pet** in dedicated-window mode. The connected dot can call `notify_reply` to place a short notice in the local inbox. No event subscription or separate chat message is required for notification delivery.
- Let ongoing dot conversations with a cached older plugin catalog send notifications through a reserved reply slot returned by the existing connection readiness check. The same local opt-in, preview limit, retry deduplication and access deadline apply.
- Show the saved reply preview as soon as the bubble opens, including its first display after launch. Fit the bounded preview in the bubble without the previous two-line truncation.
- Show incoming bubbles without requesting focus. The bubble and reply badge open the actual dedicated ChatGPT window. Text previews retain the existing explicit opt-in; the default bubble is generic.
- Keep up to 50 local notices, deduplicate retained IDs, acknowledge only the observed batch after successful display, and preserve unshown notices across restarts and hiding the pet. Consumed notices are recycled when the inbox fills; unshown notices are never silently discarded.
- Keep notification operations separate from sending/retrying relay messages. The optional receiver has no browser, filesystem-export or inference capability.

## Existing Windows installations

Install the update, then click the pet to open your default Chrome or Edge browser. The original Edge profile remains available if Edge becomes the default again. Do not copy login files between browsers.

For bubbles, enable and save **Incoming reply notifications beside the pet** in Settings. Reuse your existing authorized Near Dot plugin, reconnect its receiver if needed, and refresh its tools. Tell your dot to send a Near Dot desktop notification for replies in this conversation. New users must authorize their own private plugin connection; the installer cannot grant account permissions. Any tunnel key belongs only in the native prompt.

The receiver does not detect browser replies itself. Delivery depends on the connected dot calling the tool; enabling the setting alone does not guarantee a bubble for every response. Normal messages, conversation history, memory and model limits remain in ChatGPT. Public Mac packages retain their existing launcher.

## Validation and distribution

Regression coverage includes default-browser selection, separate caches, native Chrome/Edge window lifecycle, notification opt-in, bounds, restart, retained-ID deduplication, batch acknowledgement and fixed access deadlines. Browser checks cover persistent opt-in, dedicated-chat routing and literal preview rendering. Exact-source native CI, signed installer drills and live device evidence are recorded in the acceptance document before publication.

The existing distribution model continues: Windows installers lack Authenticode signing; Mac bundles are ad-hoc sealed without Developer ID/notarization. Mandatory updater signatures, checksums and GitHub provenance accompany the release. OS protections remain enabled.
