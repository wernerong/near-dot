# Near Dot 0.2.0-preview.1 — private Mac chat source preview

This prerelease adds direct messaging with an existing dot through an explicitly configured private MCP connection on macOS arm64. It remains a source preview: no signed public installer, production update feed or consumer connection service is included.

## Changes

- Companion click and global shortcut open a local composer with saved relay history, delivery errors and retry using the same message ID.
- Actual incoming replies appear in a separate bubble without requesting focus. Message snippets are opt-in; the companion and tray offer a read/reply action.
- Local PNG import is available from Chat and Settings. Imported images remain on the device; automatic avatar sync is unavailable.
- Rust manages a bounded Python adapter and checksum-verified official tunnel client. Quit stops owned helpers; relaunch reuses the existing authorized connection.
- The local owner can explicitly extend the initial one-hour connection window up to 24 hours. Runtime-key expiration and permissions remain separate.
- CI includes the private relay's macOS tests. Reconnect feedback, delayed-reply status and cached offline state have been cleaned up.

## Validation and limits

The Mac development build completed real existing-dot exchanges from the native composer, including an automatic incoming bubble and restart persistence. Local validation covers 15 TypeScript, 12 Rust, 24 Python and 7 browser UI/accessibility tests. Browser fixtures are synthetic and are not evidence of live replies. See [acceptance evidence](../ACCEPTANCE.md) for precise scope and performance results.

Windows remains the first planned public installer target; its chat transport is unavailable. iPhone remains a Shortcut recipe. Full ChatGPT transcript sync, global dot activity, automatic image sync, voice and ordinary-user public onboarding are unresolved. Secure MCP Tunnels are a private testing route, not a public distribution solution.

No credentials, private destinations, personal artwork or conversation records are included. Preferences retain schema 1 and optional reply snippets default off. Signed upgrade/recovery, long-duration operation, complete uninstall and total process memory remain release gates. Publishing installers and activating updates require separate review.
