## Performance measurements

Targets established for phase 1: mean idle CPU ≤1% of one core when animated, ≤0.1% when hidden; main-process RSS ≤100 MiB; combined app/WebView process memory ≤200 MiB; process launch to first UI IPC ≤2 seconds. Validate startup distribution and total memory on each supported OS before release.

`scripts/measure-macos.py` samples cumulative CPU time and RSS from `ps` once per second for 30 seconds. Results below were taken before optional image import was added and include **only the main process**, not WebKit helper memory/CPU. They cannot certify total-app budgets or the current image configuration.

| Mac arm64 mode                                       | Samples / time | Mean main CPU (one core)     | Median / peak main RSS |
| ---------------------------------------------------- | -------------- | ---------------------------- | ---------------------- |
| Animation paused                                     | 31 / 30.43 s   | 0.033%                       | 76.17 / 76.23 MiB      |
| Companion visible, animation active, Settings hidden | 31 / 30.41 s   | 0.230%                       | 82.03 / 84.23 MiB      |
| Companion and Settings hidden                        | 31 / 30.42 s   | 0.000% at sampler resolution | 79.45 / 79.53 MiB      |

Two process-cold launches reached first UI IPC in 392 ms and 398 ms, using `--measure-startup`. Filesystem caches were warm after building; these are not OS-cache-cold measurements or a p95 startup distribution. Zero reported hidden CPU is bounded by the `ps` timer resolution, not a claim of zero work. WebKit helpers and Windows measurements remain outstanding.

## Before final public review

Complete all required scenarios in [the release drill](RELEASE.md), use a user-supplied private link only on their device, confirm account availability/current official integration docs, choose the public repository and signing identity, review licenses/privacy/security, and verify sanitized artifacts/provenance. Then ask for final publication approval. Do not represent an unsigned local build as a public-ready signed release.
